# OctoAcme Project Management Docs

Welcome to OctoAcme's project management knowledge base! This README provides a high-level summary of how we run projects and links to the detailed process documents in this folder for easy navigation.

## Project Management Principles

- Customer-first: prioritize user value
- Iterative delivery in small increments
- Clear roles and responsibilities
- Data-driven decision making
- Psychological safety and feedback

## Project Lifecycle Overview

1. Initiation: define the problem, stakeholders, and top-level goals
2. Planning: define scope, identify risks, and prepare the backlog
3. Execution: build, track progress, and report status
4. Release: deploy and verify in production
5. Retrospective: review results and continuously improve
